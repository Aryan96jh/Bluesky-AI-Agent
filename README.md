# Bluesky Engagement Bot

An autonomous Bluesky bot that grows an account in the AI/crypto niche. It
discovers trending conversations, posts thoughtful AI-generated replies, and
publishes original posts — all behind strict safety gates and rate limits.

## What it does

- **Discovers** recent, high-traction posts about AI and crypto via Bluesky
  search, scoring candidates on technical depth, evidence, hype, discussion
  potential, and freshness. Low-engagement posts are skipped automatically.
- **Replies** with context-aware, niche-grounded responses generated by an LLM
  (Groq), then validated for quality and screened for spam/promotional content.
- **Posts originals** — standalone short posts built from the highest-hype
  topics it discovered, capped at 300 characters.
- **Remembers** every action in a local SQLite database so it never double-
  replies and always respects daily limits.

## Safety first

The bot **does nothing live by default**. Publishing requires two independent
gates, and even then output is throttled:

| Gate | Env var | Default |
|---|---|---|
| Dry-run mode (simulates everything) | `DRY_RUN` | `true` |
| Live execution master switch | `LIVE_EXECUTION_ENABLED` | `false` |
| Max live actions per run | `MAX_LIVE_ACTIONS_PER_RUN` | `3` |
| Max replies per day | `MAX_REPLIES_PER_DAY` | `10` |
| Max original posts per day | `MAX_ORIGINAL_POSTS_PER_DAY` | `1` |
| Delay between live actions (sec) | `ACTION_DELAY_SECONDS` | `15` |

Before any reply is published it must also pass: discovery scoring, AI
validation thresholds, a reply-quality check, and a promotion detector.

## Setup

```bash
git clone <your-repo-url>
cd bluesky-engagement-bot

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env
# Now edit .env: add your Groq API key and Bluesky handle + app password.
# (Bluesky app password: https://bsky.app → Settings → App passwords)
```

## Running

```bash
# Dry run first — simulates a full cycle without publishing anything
# (.env ships with DRY_RUN=true)

# When you're happy with the dry-run output, go live:
#   DRY_RUN=false
#   LIVE_EXECUTION_ENABLED=true
python -m app.main
```

For hands-off operation, schedule it (e.g. every 90 minutes with cron):

```cron
*/90 * * * * cd /path/to/bluesky-engagement-bot && .venv/bin/python -m app.main >> bot.log 2>&1
```

## Configuration

All behaviour is driven by `.env` (see `.env.example` for the full list):

- **Identity** — `BOT_NAME`, `BOT_NICHE`, `BOT_TONE` shape the voice.
- **Discovery** — `SEARCH_HOURS` (lookback window), `MIN_ENGAGEMENT`
  (likes + replies×3 + reposts×4), `MAX_AI_ANALYSES`, `SEARCH_LIMIT_PER_TOPIC`.
- **Replies** — `MAX_REPLIES_PER_DAY`, `MAX_LIVE_ACTIONS_PER_RUN`.
- **Original posts** — `ENABLE_ORIGINAL_POSTS`, `MAX_ORIGINAL_POSTS_PER_DAY`.
- **Quality gates** — `AI_VALIDATION_*_THRESHOLD`,
  `PROMOTION_DETECTOR_THRESHOLD`, `MIN_DISCOVERY_SCORE`.

## Notes

- Replies target posts from the last `SEARCH_HOURS` hours with real traction,
  so the account shows up in live conversations instead of dead threads.
- The bot is intentionally conservative: quality filters reject far more
  candidates than they approve. Tune thresholds in `.env` if it's too quiet.
- Keep your `.env` private. It contains your Bluesky app password and API key.

## Disclaimer

Automated engagement must respect the target platform's terms of service and
rate limits. Use responsibly-this tool is meant for genuine, high-quality
participation, not spam.
